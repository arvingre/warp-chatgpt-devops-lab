# Warp + ChatGPT DevOps Lab

基于 Warp AI + ChatGPT 的 DevOps 工作流学习与实践项目。

## 项目结构

```
warp-chatgpt-devops-lab/
 ├─ docs/          ← 项目学习过程记录
 ├─ scripts/       ← 演示脚本（shell / task）
 ├─ configs/       ← 工具配置（warp / chatgpt rules）
 └─ README.md
```

## 目标

- 探索 Warp AI 在 DevOps 场景中的应用
- 建立高效、低成本的运维工作流
- 记录最佳实践和经验总结
